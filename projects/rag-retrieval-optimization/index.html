Domain-Specific RAG Retrieval Optimization

Improving expected-evidence coverage for compound technical questions through hybrid retrieval, query decomposition, cross-encoder reranking, and source-aware context selection.

Research overview

Better coverage for multi-hop questions

A single embedding can overemphasize one part of a compound question and miss evidence located elsewhere in the documentation. This project redesigned retrieval so that each evidence need contributes candidates before the final context is assembled.

Methodology

A four-stage retrieval strategy

The interventions are cumulative: broaden the candidate pool, improve relevance ordering, then pack a diverse set of evidence into the generation context.

01

Query decomposition

Split complex requests into one to three focused subqueries so each requirement can retrieve supporting evidence.

02

Hybrid retrieval

Combine dense GTE embeddings and sparse keyword features in Qdrant using reciprocal-rank fusion.

03

Cross-encoder reranking

Use a Qwen-based cross-encoder to jointly assess each query-candidate pair and reorder the pool.

04

Source-aware packing

Build the final context from multiple relevant sources instead of allowing one manual or section to dominate.

Results

Interpretation: Recall@20 improved by 27.83 percentage points, a 44.0% relative gain. The evidence supports a claim of improved retrieval coverage—not a claim of a 28% improvement in answer accuracy.

Additional evaluation

Configuration and reliability findings

Chunk-size ablation

A 30-question experiment compared maximum chunk sizes from 1,200 to 5,000 tokens. The 2,500-token setting achieved the highest mean top-100 retrieval score, 0.9278, with complete expected evidence for 25 of 30 questions.

Operational run

A 1,000-question batch completed with zero top-level errors and an average reported source count of 4.79 per answer. One debug-stage retrieval failure was recorded, with zero debug-stage generation failures.

Key limitation

The available experiments do not quantify end-to-end answer accuracy, hallucination rate, faithfulness, citation precision, latency, or cost. Those remain important next-step evaluations.

Research outlook

A structured ontology could guide decomposition, detect missing subquestion coverage, and verify that selected evidence spans the required domain concepts before answer synthesis.
